## Reflections

**A)** I used my stiffness equation to drive my A dimension throughout the rest of my designing. This is my diameter value for feature A. This value can be seen in my CAD design and my CAD drawing on the front views.

**B)** One place that I picked a tight tolerance for example (± .005) would be thickness of feature D. This is because if the value changes much the T beam can be loose or to tight. A place that I picked a looser tolerance was a the gap. I did this because the gap tolerances are still important they just have a bigger "ok" range.
